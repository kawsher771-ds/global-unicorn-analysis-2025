# Global Startup Unicorn Analysis (2025)

An end-to-end data science project analyzing global startup unicorn density, valuation trends, and investor networks using the 2025 global unicorn dataset.

## Key Insights discovered
* **The Geo Bias:** The US and China completely dominate global unicorn density, accounting for over 65% of the total ecosystem.
* **The 2021 VC Bubble:** Built a dual-axis timeline visualizing the massive anomaly of 2021, where 452 new unicorns were minted, breaking all historic baselines.
* **Power-Law Distributions:** While the global median valuation rests at $1.6B, extreme generative AI outliers like OpenAI ($500B) drastically stretch market limits.

## Data Tech Stack
* **Data Processing:** Python, Pandas, NumPy
* **Machine Learning:** Scikit-Learn (Advanced K-Means Clustering for structural profiling)
* **Interactive Storytelling:** Plotly Express & Graph Objects, Seaborn, Matplotlib
